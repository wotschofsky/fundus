# Web library direction

The user rejected the previous warm interface and explicitly requested an absolute minimalist, modern, clean interface with a white background. This request replaces the previous palette and layout direction.

Operate mode, code-first. Plain white surfaces; system typography; neutral ink and gray hierarchy; thin separators. No decorative imagery, colored panels, icon tiles, promotional headings, gradients, shadows, or ornamental badges. Use one quiet horizontal navigation bar and a centered reading/list surface. Page headings name the task directly. Native clients retain native controls with the same simple white appearance.

The first viewport prioritizes the recording list and a findable uploader connection. On narrow screens navigation remains labeled and the content stacks without horizontal overflow. Keep readable body text, clear focus states, subtle active states, and enough separation between controls.

Opening a recording, listening from a timestamp, reading its transcript, and correcting labels or speaker identity are the primary tasks. Search returns evidence with audio time links and visible coverage. Settings creates scoped connection tokens. White does not hide warnings, destructive actions, or unknown speakers.

The signature interaction remains timestamp-linked audio with optional transcript following. Screenshots use clearly labeled synthetic demonstration content. Do not imply physical hardware testing. Web reviews certify only the supplied web evidence, not absent native screenshots.
